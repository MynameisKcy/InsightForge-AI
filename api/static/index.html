核心能力

六大技术卖点，每一项都直击一个真实数据分析痛点。

多智能体协同

痛点单个 AI 回答片面，复杂分析要人手动串联多个工具、反复提问。

方案PlannerAgent 编排 SQL -> 趋势 / 产品 / 风险 -> 可视化 -> 报告 -> 导出，步骤依赖自动调度。一句「分析近一季度各产品线销售额」，七个智能体自动接力。

沙盒安全执行

痛点让 AI 直接写 SQL，怕它删库、读文件、把系统拖垮。

方案sqlglot AST 只读沙箱，拦截多语句注入、文件读取与 DDL / DML，查询通道与管理通道强隔离。AI 生成的 SQL 只能 SELECT，删表 / 读文件一律拒绝。

SQL 智能生成与优化

痛点不会写 SQL，或写错了要反复调试。

方案自然语言转 SQL，执行报错自动回灌 LLM 重新生成（最多 3 次尝试），多表 schema 自动注入。自然语言一键取数，SQL 报错自动纠错重试。

Query 深度改写

痛点多轮对话里「它 / 上个月 / 刚才那个」让 AI 丢上下文，检索也召回不全。

方案分析桥消解指代、让 query 自包含进入规划；RAG 多查询扩展（N=3）扩召回、rerank 保精度。「分析它的趋势」-> 自动补全为「分析产品 C 近一月销售趋势」。

长短时记忆 LTM / STM

痛点每次提问都要重讲一遍背景，AI 记不住上文。

方案短期记忆 30 轮窗口 + LLM 压缩摘要；长期记忆 SQLite 持久化，保留可检索的对话历史。「上次说的那个产品」也能接上。

多格式文件解析

痛点数据散在 PDF 报告、Excel 表格、Word 文档里，要手动整理才能分析。

方案上传即分轨：表格（CSV / Excel）入 DuckDB，可直接 SQL 与跨表 JOIN；文档（PDF / Word / TXT / MD）入向量库，可问答。上传一份销售 Excel，直接问「哪个品类利润最高」。
